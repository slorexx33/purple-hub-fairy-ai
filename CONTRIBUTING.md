# Contributing

Thanks for helping improve FAIRY AI / Purple Hub!

## Before opening an issue
- Search existing issues to avoid duplicates.
- Include app version, Android version, device model, and clear reproduction steps.
- Remove API keys, passwords, email addresses, tokens, and other private data from logs/screenshots.

## Pull requests
- Keep changes focused and explain why they are needed.
- Prefer Kotlin and native Android/Jetpack Compose patterns already used in the project.
- Test the affected feature on a device or emulator when possible.
- Do not commit `google-services.json`, signing keys, generated APK/AAB files, local configuration, or personal backups.
- Update the README/changelog when user-visible behavior changes.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
