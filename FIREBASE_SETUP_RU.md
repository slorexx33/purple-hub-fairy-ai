# Подключение Firebase Authentication

Purple Hub — подключение Firebase Authentication

ВАЖНО
Код входа и регистрации добавлен в приложение, но реальные аккаунты не заработают, пока проект не подключён к Firebase. Файл google-services.json должен быть создан в ТВОЁМ Firebase-проекте. Я не могу создать Firebase-проект или OAuth-клиент от твоего имени и не добавлял чужие ключи.

ЧТО ПОДДЕРЖИВАЕТСЯ
- Регистрация по email + пароль.
- Вход по email + пароль.
- Подтверждение email по ссылке из письма.
- Повторная отправка письма подтверждения.
- Сброс забытого пароля по email.
- Google Sign-In через Android Credential Manager и Firebase Auth.
- Любой действующий почтовый домен, который принимает письма (например Proton Mail, Gmail, Outlook). Специальный список доменов в коде не задан.
- Локальный режим без аккаунта.

ПОДКЛЮЧЕНИЕ FIREBASE
1. Открой Firebase Console: https://console.firebase.google.com/ и создай собственный проект.
2. Добавь Android-приложение с package name: com.purplehub.app
3. Получи SHA-1 debug-подписи приложения. В Gradle открой задачу signingReport (обычно Tasks > android > signingReport) и скопируй SHA1 для варианта debug. Если задача доступна через терминал, выполни ./gradlew signingReport.
4. В настройках Android-приложения Firebase добавь этот SHA-1. Это требуется для Google Sign-In.
5. В разделе Authentication > Sign-in method включи Email/Password.
6. Там же включи Google и укажи адрес поддержки проекта, если Firebase попросит.
7. Скачай обновлённый google-services.json для приложения com.purplehub.app.
8. Положи файл в папку app/ проекта рядом с app/build.gradle:
   app/google-services.json
9. Выполни Gradle Sync и собери Debug APK заново.

ПОЧЕМУ НЕТ GOOGLE ВХОДА ДО ЭТОГО
Для кнопки Google требуется Web OAuth Client ID, который Firebase Gradle plugin создаёт из google-services.json. Этот файл индивидуален для твоего Firebase-проекта. В проекте включено условное подключение Google Services plugin: если файла нет, проект всё равно собирается и работает локально; если файл есть, plugin применяется и генерирует ресурсы OAuth.

КАК ПРОВЕРИТЬ
1. После подключения Firebase открой в Purple Hub Настройки → Аккаунт Purple Hub → Войти/создать аккаунт.
2. Попробуй регистрацию с адресом, к которому у тебя есть доступ. Придёт письмо подтверждения.
3. Перейди по ссылке в письме, вернись в приложение и нажми «Я подтвердил почту».
4. Затем выйди из аккаунта и проверь повторный вход.
5. Проверь «Забыли пароль?» на тестовом аккаунте.
6. Проверь кнопку «Продолжить через Google» после настройки SHA-1 и Google provider.

ЛОКАЛЬНЫЙ РЕЖИМ
Firebase-вход необязателен. Если на устройстве нет активной Firebase-сессии, приложение открывается в локальном режиме. Запустить экран входа можно через Настройки → Аккаунт Purple Hub; оттуда можно вернуться к локальному режиму.

ВАЖНО О ДАННЫХ И СИНХРОНИЗАЦИИ
5.2.0 добавляет аутентификацию, а НЕ облачную синхронизацию. FAIRY, ZZZ Companion и Password Vault продолжают хранить данные локально. Сам факт входа не загружает заметки, историю или пароли в Firebase. Не используй API-ключи или мастер-пароль Password Vault как пароль аккаунта.

ПОДПИСЬ И УСТАНОВКА
- applicationId: com.purplehub.app
- minSdk: 26 (Android 8.0)
- Для обновления поверх установленной версии подпись APK должна совпадать. Иначе Android потребует удалить предыдущую версию; заранее сохрани резервные копии.

ПРИМЕЧАНИЕ О GOOGLE SIGN-IN
Код использует Credential Manager + Google ID Token, затем передаёт токен в Firebase Authentication. Для этого требуются Google Play services, включённый Google provider в Firebase, правильный SHA-1 и актуальный google-services.json.
