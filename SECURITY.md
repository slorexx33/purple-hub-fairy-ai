# Security policy

Please do not report vulnerabilities by publishing API keys, passwords, personal data, or exploit details in a public issue.

Use GitHub's private vulnerability reporting / Security Advisories feature for this repository when available. Include the affected version, Android version, impact, and a minimal reproduction. Remove all secrets and personal information from attachments.

This is an independent community project and is provided without warranty. Avoid storing irreplaceable or highly sensitive information in the app.
