PURPLE HUB NATIVE 5.4.0 — ATTACHMENTS & LOCAL ANALYSIS

НОВОЕ
- В чат FAIRY добавлена кнопка вложений: выбор изображений из галереи, выбор файлов/документов и съёмка через системное приложение камеры.
- Поддерживается до 4 вложений на одно сообщение. Максимальный размер каждого файла — 10 МБ.
- Для изображений подключены встроенные модели ML Kit: распознавание общих объектов/сцен и OCR латинского письма.
- PDF: локальная обработка первых 4 страниц через Android PdfRenderer и OCR.
- Текстовые форматы: TXT, MD, CSV, JSON, XML, HTML. DOCX: локальное извлечение текста из document.xml.
- Извлечённые материалы передаются в контекст FAIRY вместе с текстом сообщения, только после нажатия пользователем кнопки отправки.
- Вложения отображаются в истории чата и сохраняются в FAIRY JSON backup вместе с извлечённым текстом и именами файлов.
- Добавлены плавные анимации появления карточек вложений и изменения размеров сообщений; обработка файлов выполняется не на UI-потоке.

ПРИВАТНОСТЬ И ОГРАНИЧЕНИЯ
- Локальный анализ выполняется на устройстве и не требует отдельного платного API или API-ключа.
- Временные копии выбранных файлов удаляются после обработки; исходные файлы не копируются в постоянную папку приложения.
- После отправки сообщения извлечённый текст уходит через существующий AI API, настроенный пользователем. Обычная тарификация токенов этого API сохраняется.
- ML Kit OCR распознаёт латинское письмо; кириллица на изображениях и сканированных PDF может распознаваться неточно.
- Для PDF обрабатываются только первые 4 страницы, а для каждого файла действует предел 10 МБ.
- Не поддерживаемые форматы получают карточку с сообщением о том, что локальное извлечение текста для них пока недоступно.

ТЕХНИЧЕСКОЕ
- applicationId сохранён: com.purplehub.app.
- versionCode: 21; versionName: 5.4.0.
- Добавлены ML Kit Text Recognition 16.0.1 и Image Labeling 17.0.9 (bundled-модели).
- Добавлен FileProvider для безопасной передачи URI камере; разрешение на чтение всего хранилища не запрашивается.
- Старые чаты и резервные копии остаются совместимыми; новые поля attachments необязательны для старых данных.
