PURPLE HUB NATIVE 5.3.0 — CONTROL CENTER EDITION

НОВОЕ
- Полностью переработан экран настроек: добавлен Purple Hub Control Center с шестью самостоятельными разделами.
- Голос: системный Text-to-Speech и распознавание речи; настройки автоозвучивания, языка, голоса, скорости и высоты голоса; тест воспроизведения.
- Память FAIRY: управление локальными записями — просмотр, добавление, редактирование, удаление, импорт и экспорт.
- API Monitor: накопительные счётчики запросов/ошибок/HTTP 429 с версии 5.3.0, токены по usage-ответам после обновления, измерение задержки, журнал последних 50 вызовов.
- Приватность: управление включением истории чата, передачей памяти в системный контекст AI и доступностью веб-поиска.
- Уведомления: локальные напоминания с датой и временем, системные разрешения, удаление и восстановление расписания после перезагрузки.
- Данные: экспорт/импорт FAIRY-чата, заметок, памяти и напоминаний; отдельные подтверждаемые операции очистки.

СОХРАНЕНИЕ ДАННЫХ И ПРИВАТНОСТЬ
- Настройки Control Center хранятся локально. Firebase Auth не используется для автоматической синхронизации памяти или истории.
- Память по умолчанию не передаётся AI. Её передача включается отдельным переключателем.
- Текущее сообщение пользователя отправляется провайдеру при AI-запросе; переключатель истории управляет только предыдущими сообщениями.
- API-ключ и Password Vault не включаются в FAIRY backup; ZZZ Companion использует отдельный backup.
- FAIRY JSON backup не зашифрован и может содержать личный текст; хранить его следует как приватный файл.

ТЕХНИЧЕСКОЕ
- applicationId сохранён: com.purplehub.app.
- versionCode: 20; versionName: 5.3.0.
- Kotlin Gradle Plugin и Compose Compiler Plugin остаются на 2.4.21; AGP 8.7.3; Java 17; compileSdk 35.
- google-services.json намеренно не включён в ZIP. Используй свой файл из Firebase в app/google-services.json.

ПРОВЕРКА
